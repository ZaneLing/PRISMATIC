# RxRSIAgent：未超过 GRASP，检索修复未通过升级门槛

日期：2026-10-16。状态：开发集四组实验完成并独立复核；升级被拒绝。本文是实验记录，论文方法仍统一称为 RxRSIAgent。

## 1. 当前结论

用户指出的问题成立。当前测试结果为：

| 方法 | RxSafeBench 988题 | RxQA OpenFDA 300题 |
|---|---:|---:|
| 无证据／无技能 CoT 对照 | 467（47.27%） | **193（64.33%）** |
| GRASP 作者核心任务适配 | **502（50.81%）** | 189（63.00%） |
| 固定说明书证据，无学习技能 | 499（50.51%） | 188（62.67%） |
| RxRSIAgent | 501（50.71%） | 183（61.00%） |

来源：[已保存主实验](../upgrade_v17/results/summary.json)。RxRSIAgent 比 GRASP 分别少答对1题和6题。差值区间包含零，不能据此断言统计显著更差，但更不能声称超过。RxQA 上连简单 CoT 也比当前 RxRSIAgent 高。

MedAgents、MDAgents、SafeRx-Agent 在同协议下尚未运行。把它们的名字列入表中并不等于完成了对比。当前证据不足以支持“优于现有医学 agent”的论文主张。

## 2. 这次实际运行了什么？

在调用前保存[协议](protocol.json)：相同190道 RxSafeBench 开发题、相同 DeepSeek V4.1 Flash、每题一次调用、512输出 token，固定现有技能，做检索与技能的2×2实验。旧工具使用历史完全一致请求的缓存，新工具产生380次新调用。四组共760个回答均重新核对标签、题目顺序、请求哈希和来源代码。

| 检索 | 冻结技能 | 正确数 | 准确率 | 无效输出 | 有说明书片段 |
|---|---|---:|---:|---:|---:|
| 旧 | 无 | 90/190 | 47.37% | 1 | 190/190 |
| 旧 | 有 | **99/190** | **52.11%** | 0 | 190/190 |
| 新 | 无 | 92/190 | 48.42% | 0 | 181/190 |
| 新 | 有 | 98/190 | 51.58% | 0 | 181/190 |

带技能时，新检索修复29题、破坏30题，净减少1题；差值−0.53个百分点，探索性逐题配对 bootstrap 95%区间[−8.42, 7.37]。输入 token 从517,261增至809,651。新工具失去证据的9题，旧／新带技能组均答对6题，因此不能把净退步简单归因于这9题。

**升级规则：** 新检索带技能组先在190题上严格提高正确数且不增加无效输出，再在197题 guard 上满足相同条件，才允许冻结并进入测试。本次第一关失败，未运行 guard、未重新跑测试、未替换主表配置。额外实际费用约 **$0.294**。已验证失败门槛会阻止后续阶段且不产生新调用。

## 3. 问题究竟在哪里？

**已证实：**

1. 现有技能在开发集有收益，在 RxQA 上却负迁移。以往完整387题开发集由190正确到206正确，不能当成泛化收益。
2. 旧检索器排除剂量章节、按选项全文找药名，造成 RxQA 证据覆盖只有1/300。新工具提高到214/300，但这不等于回答正确率提高。
3. 本轮新工具在 RxSafe 开发集没有提升完整 agent，且检索上下文变长。扩大检索范围不是充分的改进方案。
4. 当前技能更新直接使用 GRASP 作者核心。我们现在有处方任务适配与工具接口，但尚未证明新的、更有效的自进化机制。

**代码显示的待验证机制：** 新工具把所有匹配药品放在同一排序里取前8段，可能让某个药占满上下文；剂型和途径尚未核验。旧工具按选项分别取片段。现有技能要求每个选项都检查说明书，并把一些警示词当作排除条件，适用范围过宽。这些是需要隔离验证的原因假设，不能由本轮汇总直接证明。

## 4. 下一轮需要改变研究对象，而非增加口号

1. **先补方法对照。** 接入 MedAgents 与 MDAgents 可用作者代码，明确任务适配；报告原生调用流程及同总 token 预算。SafeRx-Agent 依可获得实现与数据确定可比范围，缺失时明确列为未测。
2. **检索按处方任务约束。** 保留按候选药均衡的证据，增加药品／剂型／途径核验与剂量问题识别；分别测证据相关性和最终回答。采用新开发协议，不把本次拒绝结果隐藏后反复修改同一协议。
3. **记忆有适用条件与反例。** 从训练失败学习“何时调用哪个工具、需要哪些患者信息、何时不应用某条经验”；对技能适用／不适用病例分别验收。人工工程修复与 agent 自己生成的更新分别报告。
4. **验证学习，而非只验证版本。** 在新的冻结评估任务上比较固定技能、普通反馈、打乱反馈、无门控和 RxRSIAgent；至少三种子，报告每轮病例数、各模块改动、修复／退步及转移表现。参数不更新就不称模型参数进化。

本轮只完成第2项之前的诊断实验；这些后续工作尚未完成。不能承诺或预设最终一定超过其他方法。

- 长期队列仍暂停。本次为独立有界实验；不是重启全部历史任务。
