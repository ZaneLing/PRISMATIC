# Numerical-state development intervention

[English results](RESULTS.en.md) · [中文结果](RESULTS.zh.md) · [Frozen protocol](protocol.json) · [Independent summary](results/summary.json)

This one-seed local pilot represents existing prior orders and labs as numerical/categorical state. Initial8k training contexts fix feature vocabularies and scales;40k training cases fit selection policies. Candidate selection uses proposal labels; one candidate is assessed against the v0.21 strong control on the same guard. There is no test scoring, API call or new clinical information.

The guard continuation rule passes, but both paired intervals include zero. A registered multi-seed/round study and untouched confirmation are still needed. The order tool remains fixed; this experiment does not claim autonomous skill or code evolution.

Run `run_development.py`, followed by `summarize.py`. Patient-level artifacts and learned parameters remain in the restricted directory.
