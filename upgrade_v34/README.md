# Scoped memory and medical-agent comparison

The completed report is generated by `report.py` after `audit.py` independently recounts all outputs. The retained main RxRSIAgent checkpoint is unchanged. Raw receipts, public case text and credentials are stored outside this repository.

## Reproduction

Use the project's existing Python environment and public-data/cache layout from `upgrade_v8/public_client.py`. Additional author-code dependencies are `jsonlines`, `nltk`, `rouge-score`, `termcolor`, `prettytable` and `pptree`; NLTK requires `punkt` and `punkt_tab`. Author repositories must be present at the revisions in `protocol.json`. The adapter validates their source hashes. No secret belongs in a command or commit.

```bash
python upgrade_v34/run_comparators.py --method medagents --split proposal --workers 32
python upgrade_v34/run_comparators.py --method medagents --split test --workers 32
python upgrade_v34/run_comparators.py --method medagents --split rxqa --workers 32
python upgrade_v34/run_comparators.py --method medagents --split medqa --workers 32
# Repeat the four splits with --method mdagents.
# Repeat learning for seeds 42, 137 and 2026; freeze all states before transfer.
python upgrade_v34/run_memory.py --seed 42 --stage learn
python upgrade_v34/run_memory.py --seed 42 --stage transfer
python upgrade_v34/audit.py
python upgrade_v34/report.py
python paper/render_acl.py
```

Do not regenerate a different task membership or silently modify frozen model, parser, instructions, update gates or memory implementation. The protocol refuses source mismatches. Exact-cache reuse is disclosed; fresh provider runs may differ despite the same model identifier. Runtime concurrency can vary without changing method inputs.

## Artifacts

- `protocol.json`, `comparison_freeze.json`: author pins, adaptations, task selection and test freeze.
- `memory_protocol.json`: learning conditions and pre-transfer development amendment.
- `results/independent_transfer_freeze.json`: all three state sequences frozen before independent-task inference.
- `results/*-manifest.json`: split membership hashes and model configuration.
- `results/medagents-*.json`, `results/mdagents-*.json`: completed aggregate method runs.
- `results/memory-seed*.json`, `results/transfer-seed*.json`: learning/transfer curves.
- `results/audit.json`: recounts, raw receipt checks, paired intervals and gate verification.
- `protocol_history/`, `development_history/`, explicitly prefixed debug result files: development attempts retained for provenance, excluded from formal comparison rows.

The `+10pp` objective is an engineering target over the strongest executed comparator. The experiment does not meet it. No unavailable clinical evaluation is treated as passed.
