# RxRSIAgent 临床适当性与规则审查规程

## 目标与边界

研究问题分为两个部分：一是预测未来六小时实际记录的新增/修改订单；二是依据决策时已知信息，这些用药建议是否合理。两者分别评分。真实订单也可能依赖之后的信息；不能把与 GT 不同直接判为临床错误。

本规程参考 [WHO 合理处方教学框架](https://iris.who.int/handle/10665/67010) 与 [Medication Appropriateness Index 原始研究](https://doi.org/10.1016/0895-4356(92)90144-C)。这里是研究用改编规程，不是已验证 MAI 总分；不计算未经验证的合成安全分。

## 双人独立盲评

1. 每位评审者获得同样32位患者：16位单系统、16位多系统；在各层内按固定哈希抽样，不按改善情况挑选。
2. 先只看 hour6 之前的上下文，填写治疗目标、必要的新增/修改措施和缺失信息，再打开候选订单。
3. 候选包括固定 agent、首个预设顺序的 RxRSIAgent、固定监督工具和实际未来订单。来源隐藏，展示顺序独立随机化；相同订单集合合并一次评分。不要向评审者提供解盲文件。
4. 每份订单独立评估：适应证、对治疗目标的有效性、剂量、途径、频次、疗程、DDI、药物-疾病冲突、肝肾功能调整、重复用药、监测和执行可行性。允许 `appropriate / marginal / inappropriate / unknown / not_applicable`。
5. 单独记录遗漏的必要措施、多余措施、错误严重性与依据。分母为可评估项目；同时报告 unknown 比例，禁止把 unknown 当作通过。
6. 两位先独立完成，再对 major/critical 分歧进行共同复核。保留原始评分和最终结论；未达共识则保留 unresolved。报告原始一致率及适用时的加权 kappa，不用共识覆盖原始分歧。

## 技能审查

对每条唯一规则分别核对：诊断条件是否与该药物/治疗目标存在临床关系；这是合理的订单预测规则还是不当停药建议；反例是否真实存在；是否缺少关键禁忌、疗程、续开或病情变化条件；是否有可靠来源支持。`unless=[]` 不能解释成“无需反例”。不根据规则的实验分数决定临床合理性。
